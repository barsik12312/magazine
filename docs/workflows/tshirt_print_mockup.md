# Воркфлоу: Идеальный принт на футболке через Photopea

Этот гайд решает главную боль ИИ-генерации футболок — **сломанный текст на принте**. Метод даёт 100% точный принт за ~5 минут.

---

## Когда использовать

После того как Nano Banana Pro выдал хороший общий вид (футболка, фон, посадка, складки), но текст принта сломан/искривлён.

**Не используй этот метод как замену генерации** — нужно сначала получить базовую футболку из Gemini, потом доработать принт.

---

## Что нужно

1. **Результат из Gemini** — PNG/JPG футболки (с любым принтом, даже сломанным)
2. **PNG настоящего принта** — твой исходный дизайн на прозрачном фоне или белом
3. **Photopea** — открыть https://www.photopea.com (бесплатно, никакой регистрации, работает в браузере)

---

## Метод A: Простая замена принта (3 минуты, для плоских футболок)

Подходит когда футболка на вешалке — складки минимальные.

### Шаги

1. Открой Photopea: https://www.photopea.com
2. **File → Open** → выбери результат от Gemini (футболку)
3. **File → Open & Place** → выбери PNG принта
   - Принт появится как отдельный слой поверх футболки
4. **Ctrl+T** (Free Transform):
   - Подгони размер принта так, чтобы перекрыть существующий принт от Gemini
   - Подвинь в правильное место
   - Если нужно — наклони (Edit → Transform → Skew/Rotate)
   - Enter для применения
5. На панели слоёв (справа), у слоя с принтом:
   - **Blending Mode** = **Multiply** (это сделает белый фон принта прозрачным)
   - Или **Linear Burn** если Multiply слишком сильный
6. **Opacity** = 90-95% (чтобы принт чуть-чуть "впитался" в футболку, выглядел естественно)
7. (опционально) **Filter → Blur → Gaussian Blur** → 0.3-0.5 px на принт (мягкость краёв, как настоящая краска)
8. **File → Export As → PNG** → сохрани

**Результат:** идеальный текст на футболке без AI-косяков.

---

## Метод B: С displacement-картой (5-7 минут, для футболок со складками)

Подходит когда на футболке видны складки, и ты хочешь чтобы принт реалистично искривлялся по ним.

### Шаги

1. **Открой результат от Gemini** в Photopea
2. **Сделай displacement-карту:**
   - Image → Mode → **Grayscale** (Photopea: Image → Mode → Grayscale)
   - Filter → Blur → **Gaussian Blur** → 3-5 px (сглаживаем мелкий шум)
   - File → Save as PSD → сохрани как `displace.psd` на компьютер
   - **Откати:** Edit → Undo (или открой исходник заново — нам нужна цветная футболка)
3. **Положи принт поверх:**
   - File → Open & Place → выбери PNG принта
   - Ctrl+T → подгони размер и позицию
   - Blending Mode = **Multiply**
4. **Применить displacement:**
   - Выбери слой с принтом (только принт!)
   - Filter → Distort → **Displacement Map**
   - Horizontal scale: **5-8**, Vertical scale: **5-8**
   - Stretch to fit / Repeat edge pixels
   - OK → выбери `displace.psd`
   - Принт чуть-чуть искривится по складкам — теперь он выглядит как настоящая печать
5. (опционально) Добавь шум:
   - Filter → Noise → Add Noise → 1-2%, Gaussian, monochromatic
6. (опционально) Добавь сетку ткани:
   - Создай новый слой поверх → залей серым → Filter → Texture → Texturizer → Canvas (если есть)
   - Blend Mode = Soft Light, Opacity = 10-15%
7. **Export → PNG**

**Результат:** принт реалистично "вмят" в ткань, искривляется по складкам.

---

## Метод C: Только текстовая правка (1 минута)

Если общая композиция принта правильная, но 1-2 буквы сломаны:

1. Открой результат в Photopea
2. **Clone Stamp Tool** (S):
   - Зажми Alt и кликни на чистую часть футболки рядом с принтом
   - Закрась сломанную букву
3. **Type Tool** (T):
   - Кликни в нужное место
   - Напечатай правильную букву
   - Подбери шрифт (Arial Black / Helvetica / Impact — пробуй пока не совпадёт)
   - Размер и цвет — как соседние буквы
4. (если шрифт чуть отличается) Filter → Blur → Gaussian → 0.3 px
5. Export → PNG

---

## Бонус: Где брать чёрные шрифты для принтов

Если PNG принта нет, нужно сделать с нуля:

- **Heavy sans-serif** (для уличного стиля): Arial Black, Helvetica Bold, Impact, Bebas Neue (бесплатный)
- **Geometric**: Futura Bold, Avenir Heavy
- **Display / лого-стиль**: Tungsten, Druk Wide
- Бесплатные коллекции: https://fonts.google.com (Bebas Neue, Anton, Oswald — все бесплатные и гото внешне)

---

## Когда стоп — оставлять как есть

Если принт **примерно похож** (даже с 1-2 кривыми буквами), для быстрых маркетплейсных карточек этого может быть достаточно. Покупатели редко вглядываются в шрифт. Запас времени тратишь только на:
- Главные карточки (превью на витрине)
- Премиум-товары
- Lookbook / brand-line
