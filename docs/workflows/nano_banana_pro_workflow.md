# Воркфлоу: Nano Banana Pro в Gemini

Полный путь "идея → 5 готовых картинок для маркетплейса" через подписку на Gemini AI Plus / Pro.

---

## 1. Что такое Nano Banana Pro

Это народное название модели **Gemini 3 Pro Image** от Google. Доступна:
- В чате **gemini.google.com** при активной подписке Google AI Plus ($7.99/мес) или Pro ($19.99/мес).
- Через API (Imagen / Gemini Image API) — не используем в этом репо, всё делаем в браузере.

**Сильные стороны:**
- Multi-image composition (берёт твои 2-5 фото и компонует)
- Удерживает консистентность между кадрами в одном чате
- Лучше работает с длинными подробными промптами (1500+ символов)
- Понимает русский, но **на английском работает чище**, особенно с текстом

**Слабые стороны:**
- Сложные шрифты / редкие принты иногда ломаются — финиш в Photopea (см. `tshirt_print_mockup.md`)
- Лица моделей: похоже на референс, но не 1-в-1
- Может слегка плавать цвет между кадрами (фиксится Color Balance в Photopea)

## 2. Подготовка (один раз)

1. Купи подписку на https://gemini.google/subscriptions/ (Plus достаточно для старта)
2. Зайди на https://gemini.google.com
3. В шапке чата выбери модель **"Nano Banana Pro"** (она же Gemini 3 Pro Image)
4. В настройках чата включи **4K вывод** (если есть в твоём тарифе)

## 3. Цикл работы (на каждое задание)

### Шаг А — собираешь исходники
- Фотки товара (свои или с Авито/Wildberries)
- Если есть PNG принта — отдельно (для футболок особенно)
- Референсы (фон, поза, типаж модели)

### Шаг Б — запускаешь скрипт
Собери папку с исходниками по [docs/INPUT_FOLDER_CONVENTION.md](../INPUT_FOLDER_CONVENTION.md) и натрави на неё скрипт:

```bash
python scripts/build_task.py \
  --type tshirt \
  --slug my-new-tee \
  --input inputs/2026-05-04_my-new-tee/
```

Скрипт сам разберёт файлы (`1`/`2`/`3`, `спереди`/`сзади`/`бирка`, `фон`/`модель`/`задание`) и создаст папку `stores/tshirts/tasks/<timestamp>_my-new-tee/` с:
- `READY_FOR_GEMINI/` — то, что грузишь в Gemini
- `READY_FOR_GEMINI/refs/` — нормализованные исходники (имена `print_1_front.*`, `garment_front.*`, `scene_*.*`, ...)
- `outputs/` — куда сохраняешь готовые картинки
- `inputs_snapshot/` — снимок исходников
- `00_BRIEF.md` — твоё ТЗ для контекста

### Шаг В — генерируешь в Gemini
1. Открой `READY_FOR_GEMINI/README.txt` и `00_BRIEF.md` — там что и зачем
2. Для каждого ракурса:
   - Открой соответствующий `0X_PROMPT_*.txt`
   - Скопируй промпт в чат Gemini
   - Прикрепи файлы из `refs/` в порядке, указанном в промпте
   - Отправь, итерируй до результата
3. Шаги 04/05 (на модели) запускай ПОСЛЕ шагов 01/02 — там в качестве референса используются твои готовые `result_front.*` / `result_back.*`
4. Сохраняй финал в `outputs/` (имена не важны)

### Шаг Г — финальная доработка (если нужно)
- Сложный текст / принт сломан → Photopea (см. `tshirt_print_mockup.md`)
- Цвет плавает → Color Balance в Photopea
- Загружаешь на маркетплейс / в магазин

## 4. Принципы для качественного результата

### 4.1 Один чат на одно задание
Не открывай новый чат под каждый ракурс. Pro помнит контекст в рамках чата — это ключ к консистентности.

### 4.2 Длинные подробные промпты
1500-3000 символов — норма. Расписывай:
- Точный товар (цвет, материал, крой)
- Точный принт (буквы, шрифт, цвет, размер)
- Точный фон (стены, мебель, освещение)
- Камеру (фокусное, диафрагма, ракурс, aspect ratio)
- Качество ("photorealistic", "no AI artifacts")
- Запреты ("do NOT change spelling", "no extra fingers")

### 4.3 Английский в промпте
Pro понимает русский, но на английском работает чище. Особенно для:
- Точного отображения текста на принтах
- Сложных композиций
- Технических терминов (focal length, aspect ratio)

### 4.4 Iterative refinement
Не ждёшь идеала с первой генерации. Получил → посмотрел что не так → пишешь:
> "Keep this image but: (1) the print should match image 1 exactly,
> (2) make the lighting warmer, (3) shorten the hair slightly"

Pro отлично умеет точечные правки.

### 4.5 Консистентность через референсы
Чем больше релевантных фото в чате, тем лучше:
- 1-2 фото товара (углы)
- 1 фото фона
- 1 фото модели/типажа
- 1 PNG принта (если есть)

Оптимально: 3-5 файлов на промпт.

## 5. Когда переходить в Photopea

| Проблема | Photopea |
|----------|----------|
| Текст принта / бирки сломан после 3+ итераций | ✅ Да |
| Нужен идеально-точный логотип бренда | ✅ Да |
| Цвет плавает между кадрами | ✅ Да (Color Balance) |
| Нужно убрать единичный артефакт (лишний палец, ляп) | ✅ Да (Clone Stamp) |
| Нужно объединить несколько результатов | ✅ Да |
| Общая композиция не та | ❌ Лучше переделать в Gemini |

См. `tshirt_print_mockup.md` для пошагового гайда по Photopea.

## 7. Альтернативы (когда Pro не справляется)

- **Photopea** для финального текста / принтов / коррекции цвета (бесплатно)
- **Kling AI Virtual Try-On** для виртуальной примерки (бесплатно базовый тариф) — особенно для одевания твоей реальной модели в твою одежду
- **Flux Kontext** через fal.ai — backup-генератор когда Pro выдаёт стабильно плохо
- **GPT-Image-1** в ChatGPT — лучший на момент 2026 для рендеринга текста на принтах (если у тебя есть подписка на ChatGPT)
