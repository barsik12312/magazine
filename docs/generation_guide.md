# 🔬 Детальный гайд по ИИ-генерации изображений

> Этот документ описывает **конкретные возможности и ограничения** встроенного генератора изображений, доступного через Antigravity (Gemini-based агент).

---

## 1. Как работает генерация

### Инструмент: `generate_image`

Генератор вызывается через встроенный инструмент с двумя параметрами:

```
Prompt: текстовое описание желаемого изображения (на английском)
ImagePaths: до 3 изображений-референсов (абсолютные пути к файлам)
```

### Что происходит внутри
1. Текстовый промпт отправляется в модель генерации (Imagen / Gemini Image Generation)
2. Если переданы `ImagePaths`, изображения загружаются как **визуальный контекст**
3. Модель генерирует **одно** изображение за вызов
4. Результат сохраняется как PNG файл

### Формат вывода
- **Формат:** PNG
- **Размер:** определяется моделью автоматически (обычно ~1024×1024 или по aspect ratio)
- **Количество:** 1 изображение за вызов (нет batch-генерации)

## 2. Что МОЖЕТ генератор

### ✅ Хорошо справляется

| Задача | Качество | Пример |
|--------|----------|--------|
| Общие фото товаров без текста | ⭐⭐⭐⭐ | Платья, обувь, аксессуары на нейтральном фоне |
| Студийные фоны | ⭐⭐⭐⭐ | Шкафы, рейлы, интерьеры, абстрактные фоны |
| Модели в одежде (общий стиль) | ⭐⭐⭐ | Человек в футболке/платье без сложных деталей |
| Lifestyle/атмосферные фото | ⭐⭐⭐⭐ | Модель на улице, в кафе, на балконе |
| Переделка скриншотов в студийные фото | ⭐⭐⭐ | Улучшение качества, замена фона |
| Общая стилистика (по референсу) | ⭐⭐⭐ | Похожий ракурс, освещение, настроение |

### ✅ Использование референсных изображений

```
ImagePaths: ["путь/к/фото1.jpg", "путь/к/фото2.jpg", "путь/к/фото3.jpg"]
```

- **Максимум 3 изображения** за один вызов
- Изображения передаются как **визуальный контекст**, а не как точный шаблон
- Модель **вдохновляется** референсами, но **НЕ копирует** их точно
- Лучше всего работает для передачи: общего стиля, ракурса, цветовой палитры, типа фона
- Форматы: JPG, PNG, WebP

### ✅ Промпт-инжиниринг

- Работает на английском языке
- Чем детальнее описание — тем лучше результат
- Эффективные ключевые слова:
  - `photorealistic`, `shot on iPhone 15 Pro` — для реализма
  - `no AI artifacts` — для чистоты
  - `realistic fabric texture with natural wrinkles` — для ткани
  - `natural skin texture with visible pores` — для кожи
  - Конкретные параметры камеры: `85mm, f/2.8, shallow depth of field`
  - Тип освещения: `soft natural daylight`, `studio lighting`

## 3. Что НЕ МОЖЕТ генератор

### ❌ Критические ограничения

| Задача | Проблема | Решение |
|--------|---------|---------|
| **Точный текст на одежде** | Буквы искажены, переставлены, нечитаемы | ComfyUI + inpainting текста отдельно |
| **Точный перенос принта** | Принт выглядит как "наклеенный в фотошопе", не следует складкам ткани | SD + depth map + ControlNet |
| **1:1 копия лица модели** | Передаёт общий типаж, но не точное лицо | IP-Adapter / InstantID / Face swap |
| **Консистентность между фото** | Каждое фото — "новый мир", детали меняются | Seed control (нет доступа) |
| **Конкретный логотип/бренд** | Генерирует "что-то похожее", но не точную копию | Inpainting поверх сгенерированного |
| **Бирка с конкретным текстом** | Текст на бирке нечитаем или неправильный | Фотошоп / Canva поверх |
| **Batch-генерация** | 1 изображение за вызов, нет пакетной обработки | Скрипт с API (нет прямого доступа) |
| **Контроль seed** | Нет возможности фиксировать seed для воспроизводимости | ComfyUI / A1111 |
| **Inpainting (частичное редактирование)** | Нельзя заменить только часть изображения | ComfyUI + inpaint mask |
| **Img2Img (точная переработка)** | Нет режима image-to-image с контролем strength | ComfyUI / A1111 |
| **ControlNet** | Нет контроля позы/композиции через скелет/depth | ComfyUI + ControlNet |
| **LoRA / Fine-tuning** | Нельзя дообучить модель на конкретном лице/стиле | Kohya / ComfyUI + LoRA |

### ❌ Конкретные проблемы, обнаруженные на практике

1. **Принт "No FUCKS GIVENCHY":**
   - Текст на футболке генерируется с ошибками (буквы не те, порядок нарушен)
   - Стилизованные CC-буквы внутри текста не воспроизводятся
   - Принт выглядит "плавающим" поверх ткани, а не напечатанным

2. **Серфборд на спине:**
   - Общая форма передаётся
   - Полоски и CC-логотип внутри — нестабильны
   - Масштаб и позиционирование на футболке могут меняться

3. **Модель на фото:**
   - Даже с референсом — модель выглядит как другой человек
   - Футболка на модели может отличаться от футболки на вешалке
   - Поза передаётся примерно, но не 1-в-1

4. **Бирка:**
   - Генерирует общую "бирку", но текст на ней рандомный
   - Нельзя указать конкретный бренд/размер

## 5. Параметры generate_image (полный справочник)

### Параметры вызова

```python
generate_image(
    Prompt: str,          # Текстовое описание (ОБЯЗАТЕЛЬНО)
    ImagePaths: list[str], # До 3 путей к файлам-референсам (ОПЦИОНАЛЬНО)
    ImageName: str         # Имя выходного файла (ОБЯЗАТЕЛЬНО)
)
```

### Эффективные промпт-паттерны

#### Для товарной фотографии:
```
Professional product photo of a [ITEM] on [SURFACE/HANGER].
[BACKGROUND DESCRIPTION]. [LIGHTING]. Shot on [CAMERA],
[LENS]mm, f/[APERTURE]. Realistic [MATERIAL] texture.
No AI artifacts. Aspect ratio [RATIO].
```

#### Для модельной съёмки:
```
[STYLE] photo of a [MODEL DESCRIPTION] wearing [CLOTHING].
[POSE]. [BACKGROUND]. [LIGHTING]. Shot on [CAMERA].
Realistic skin texture with visible pores, natural hair.
No AI artifacts. Aspect ratio [RATIO].
```

#### Для улучшения скриншотов:
```
Professional studio photo of [PRODUCT DESCRIPTION].
Remove watermarks. Clean [BACKGROUND COLOR] background.
Professional studio lighting. Color-accurate reproduction.
Camera: 50mm, f/4. Aspect ratio [RATIO].
```

### Что включать в промпт (чеклист):
- [ ] Тип фото (product/lifestyle/catalog/macro)
- [ ] Описание предмета (цвет, материал, крой)
- [ ] Фон (конкретные элементы)
- [ ] Освещение (направление, жёсткость, температура)
- [ ] Камера (тип, фокусное, диафрагма)
- [ ] Текстуры (ткань, кожа, металл)
- [ ] Негативные ограничения (no AI artifacts, no watermarks)
- [ ] Соотношение сторон

### Что НЕ включать:
- Точный текст (будет с ошибками)
- Конкретные логотипы брендов (будут искажены)
- Ссылки на конкретных людей
- Слишком много деталей в одном промпте (модель "путается")

## 6. Лучшие практики

### Для максимального качества:

1. **Разделяй сложные задачи** — генерируй футболку без принта, потом добавляй принт отдельным инструментом
2. **Используй реальные фото как референс** — передавай через `ImagePaths` фото с правильным фоном/ракурсом
3. **Не пытайся генерировать текст** — любой текст на одежде будет с ошибками
4. **Генерируй несколько вариантов** — из 3-5 генераций выбирай лучшую
5. **Проверяй руки и пальцы** — классическая проблема ИИ-генерации

### Для консистентности между фото:

1. Используй **одинаковый промпт-шаблон** для серии (меняй только принт/цвет)
2. Передавай **одно и то же фото фона** как референс
3. Описывай фон **максимально конкретно** (не "красивый фон", а "dark emerald velvet curtain, black plastic hanger on white window handle, green potted ficus plant on the right, dark metal shelf-ladder")
