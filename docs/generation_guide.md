# Гайд по генерации картинок: инструменты и подход

Этот документ — обзор того, какими инструментами генерируем фото и почему. Конкретная пошаговая работа с Nano Banana Pro лежит в [docs/workflows/nano_banana_pro_workflow.md](workflows/nano_banana_pro_workflow.md).

---

## Главный инструмент: Nano Banana Pro

**Nano Banana Pro** = народное название модели **Gemini 3 Pro Image** от Google. Доступна:
- В чате https://gemini.google.com (нужна подписка)
- Через Imagen API (не используем в этом репо)

### Почему именно Pro, а не базовая Nano Banana

| Возможность | Nano Banana (базовая) | **Nano Banana Pro** |
|-------------|------------------------|---------------------|
| Простая генерация по тексту | ✅ | ✅ |
| Multi-image composition (брать твои фото) | ⚠️ ограниченно | ✅ |
| Длинные подробные промпты (1500+ симв.) | ⚠️ начинает терять детали | ✅ держит |
| Текст на принтах/бирках | ❌ ломает | ⚠️ часто получается, иногда нужен Photopea |
| Iterative refinement в чате | ✅ | ✅ хорошо |
| Консистентность модели между кадрами | ⚠️ слабо | ✅ хорошо |
| 4K-вывод | ❌ | ✅ (в Plus/Pro) |

Базовая Nano Banana — то, что использовал Antigravity на первом задании. Результат: общий вид норм, текст принта сломан. Pro этого избегает в большинстве случаев, остаётся только мелкая доработка через Photopea для критичного текста.

### Где взять Pro

| Подписка | Цена | Когда брать |
|----------|------|-------------|
| **Google AI Plus** | $7.99/мес | **Старт. Достаточно для 95% задач** |
| Google AI Pro | $19.99/мес | Если упрёшься в дневной лимит Plus |
| Google AI Ultra | $249/мес | Не нужен для нашего кейса |

Подписка: https://gemini.google/subscriptions/

## Что умеет / не умеет Pro

### Умеет хорошо

- **Фотореалистичные товарные фото** на хорошем уровне (футболка, бельё, одежда)
- **Multi-image композицию**: бери фото модели + товара + фона → собирает в кадр
- **Сохранять стиль между кадрами одного чата** — серия из 5 фото в одном look
- **Удалять ватермарки и UI** со скриншотов Авито (одной командой)
- **Менять фон / освещение / цвет** сохраняя товар
- **Естественные позы и анатомию** на 95% случаев

### Делает с переменным успехом

- **Текст на принтах/бирках** — иногда идеально, иногда с переставленными буквами. Норма: попросить перерендерить 1-3 раза, если не помогло — финиш в Photopea.
- **Лица моделей 1-в-1** — даёт похожесть, но не точную копию. Для маркетплейсов это часто плюс (избегаем "это конкретная девушка").
- **Очень мелкие детали** (мелкие швы, специфические клёпки) — может упростить.

### Не делает / делает плохо

- **Точное воспроизведение специфических логотипов брендов** — если шрифт нестандартный
- **Гарантированно консистентное лицо в десятках кадров** — для Lookbook со 100% узнаваемой моделью лучше использовать **Kling AI Virtual Try-On** или **face-swap в Photopea**
- **Работа без подписки** — у бесплатной версии Gemini нет Pro

## Когда использовать Photopea (бесплатно)

[Photopea](https://www.photopea.com) — браузерный аналог Photoshop. Бесплатный, без регистрации.

Используем для финальной доработки результатов Pro:

| Задача | Метод | Гайд |
|--------|-------|------|
| Текст принта сломан | Замена слоя + Multiply + Displacement | [tshirt_print_mockup.md](workflows/tshirt_print_mockup.md) |
| Текст бирки гибериш | Type Tool поверх | tshirt_print_mockup.md |
| Цвет плавает между кадрами | Image → Adjustments → Color Balance | nano_banana_pro_workflow.md |
| Артефакт (лишний палец) | Clone Stamp | очевидно |
| Удалить ватермарк | Clone Stamp / Pro обычно сам удаляет | clothing_avito_rework.md |

**Принцип:** если 3-4 итерации в Pro не помогают — переходи в Photopea, обычно 5 минут работы.

## Альтернативы (бэкап и спецзадачи)

### Kling AI Virtual Try-On
- Что: одевает реальную модель в реальную одежду по фото
- Когда: для футболок-на-моделях когда хочется именно твою модель в твоей одежде
- Тариф: бесплатный базовый
- URL: https://kling.kuaishou.com/en

### Flux Kontext (через fal.ai)
- Что: альтернативная image-edit модель
- Когда: backup если Pro даёт стабильно плохо на конкретной задаче
- Тариф: ~$0.05/картинка по факту использования
- URL: https://fal.ai/models/fal-ai/flux-pro/kontext

### GPT-Image-1 (ChatGPT)
- Что: генератор картинок от OpenAI
- Когда: лучше всех на момент 2026 рендерит **текст на принтах** — реальный конкурент Pro
- Тариф: $20/мес ChatGPT Plus
- URL: https://chatgpt.com

### Локальные модели (ComfyUI)
- Не используем. Перебор для нашего кейса. Только если ты упрёшься в деньги/лимиты подписок.

## Как мы организуем работу

1. **Скриптом** `scripts/build_task.py` собираем готовую папку под задание
2. **Руками** работаем в браузере с Gemini (Nano Banana Pro)
3. **Иногда** доводим в Photopea
4. **Сохраняем** финальные картинки в `outputs/` соответствующего задания

Полный цикл расписан в [docs/workflows/nano_banana_pro_workflow.md](workflows/nano_banana_pro_workflow.md).
