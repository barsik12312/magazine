  ИНСТРУКЦИЯ ДЛЯ NANO BANANA PRO (Gemini)
  Задание 1 — карточка футболки "N° FUCKS GIVENCHY"
═══════════════════════════════════════════════════════════════════════

  ШАГ 0 — ПОДГОТОВКА (один раз перед всеми генерациями)
───────────────────────────────────────────────────────────────────────

  1. Открой https://gemini.google.com (с активной подпиской AI Plus или Pro)
  2. Создай новый чат
  3. Сверху выбери модель: "Nano Banana Pro" (или "Gemini 3 Pro Image")
     ⚠️ НЕ обычный Gemini — именно с пометкой Image / Pro Image
  4. В настройках чата (если есть) включи 4K вывод

  ШАГ 1 — ГЕНЕРАЦИЯ FRONT_HANGER (фото 1 из 5)
───────────────────────────────────────────────────────────────────────

  1. Открой файл:    01_PROMPT_FRONT_HANGER.txt
  2. Выдели весь текст (Ctrl+A) → Скопируй (Ctrl+C)
  3. В чат Gemini вставь промпт (Ctrl+V), но пока НЕ отправляй
  4. Через скрепку 📎 (или drag&drop) загрузи в это сообщение:
       • 01_print_FRONT_design.jpg       ← это станет "image 1" в промпте
       • 02_layout_FRONT_mockup.jpg      ← image 2
       • 04_reference_REAL_tshirt_FRONT_in_wardrobe.jpg ← image 3
       • 06_reference_REAL_tshirt_CLOSEUP.jpg            ← image 4
  5. Проверь порядок — он критичен (промпт ссылается на номера)
  6. Отправь сообщение
  7. Получишь картинку. Если результат плохой:
       • Если принт сломан: ответь "Print is incorrect. The exact print
         is in image 1. Re-render the t-shirt with this exact print —
         do NOT change letters or add new elements."
       • Если фон не такой: ответь "Background should match image 3
         exactly — same green velvet curtain, same hanger, same plant"
       • Если общий вид не тот: пиши конкретно что не так
  8. Когда финал устраивает — скачай PNG, переименуй в:
       outputs/01_front_hanger.png

  ШАГ 2 — ГЕНЕРАЦИЯ BACK_HANGER (фото 2 из 5)
───────────────────────────────────────────────────────────────────────

  1. В ТОТ ЖЕ ЧАТ (важно — Pro помнит контекст!)
  2. Открой 02_PROMPT_BACK_HANGER.txt → скопируй
  3. Прикрепи изображения:
       • 03_layout_BACK_mockup.jpg       ← image 1 (новое)
       • 05_reference_REAL_tshirt_BACK_in_wardrobe.jpg ← image 2 (новое)
     (предыдущие изображения уже в памяти чата — ссылайся "the same scene
     as in the previous front shot, but back view")
  4. Отправь, итерируй до результата
  5. Сохрани → outputs/02_back_hanger.png

  ШАГ 3 — ГЕНЕРАЦИЯ TAG (бирка крупным планом)
───────────────────────────────────────────────────────────────────────

  1. В ТОТ ЖЕ ЧАТ
  2. Открой 03_PROMPT_TAG.txt → скопируй → отправь
     (новые референсы не нужны — Pro использует футболку из предыдущих кадров)
  3. ВАЖНО: текст на бирке часто получается неправильным с первого раза.
     Если текст "FUCK GIVENCHY" сломан — попроси: "The brand name on
     the tag must be exactly 'FUCK GIVENCHY' — re-render with correct
     spelling, sharp legible text"
  4. Если после 3-4 итераций текст всё равно ломается:
       → принимаем как есть и финишируем в Photopea (см. KNOWN_ISSUES.txt)
  5. Сохрани → outputs/03_tag.png

  ШАГ 4 — ГЕНЕРАЦИЯ MODEL_FRONT (фото на модели, спереди)
───────────────────────────────────────────────────────────────────────

  1. В ТОТ ЖЕ ЧАТ
  2. Открой 04_PROMPT_MODEL_FRONT.txt → скопируй
  3. Прикрепи:
       • 07_reference_MODEL_pose_FRONT.jpg ← image 1 (новое — поза/типаж модели)
  4. Отправь. Итерируй:
       • Если лицо не нравится: "Make the model's face less visible —
         crop higher or have him look down slightly. We don't need a
         specific face."
       • Если принт сломан: см. фикс в шаге 1
  5. Сохрани → outputs/04_model_front.png

  ШАГ 5 — ГЕНЕРАЦИЯ MODEL_BACK (фото на модели, сзади)
───────────────────────────────────────────────────────────────────────

  1. В ТОТ ЖЕ ЧАТ
  2. Открой 05_PROMPT_MODEL_BACK.txt → скопируй
  3. Прикрепи:
       • 08_reference_MODEL_pose_BACK.jpg ← image 1 (новое)
  4. Отправь, итерируй
  5. Сохрани → outputs/05_model_back.png
