# 🏪 Magazine — ИИ Фото-продакшен для маркетплейсов

Система генерации профессиональных товарных фотографий для нескольких розничных направлений.

## 📁 Структура проекта

```
Magazine belya/
├── data/
│   ├── models/              # Досье моделей (описание внешности, референсы)
│   │   └── template_dossier.md
│   └── products/            # Исходные фото товаров
├── prompts/
│   ├── Арт директор.md      # Мастер-промпт для структурирования заданий
│   ├── brand_style.md       # Единый визуальный стандарт всех магазинов
│   └── templates/           # Шаблоны промптов по категориям
│       ├── tshirt_hanger.md     # Футболки (5 ракурсов)
│       ├── lingerie_studio.md   # Белье (3 ракурса)
│       └── clothing_catalog.md  # Одежда + переработка Авито-скринов
├── output/                  # Готовые результаты по категориям
│   └── футболки/
├── фотки белье/             # Исходники и референсы белья
├── фотки футболки/          # Реальные фото футболок (фоны, принты)
├── фотки одежда/            # Скриншоты Авито + примеры генерации
├── Первое задание по футболкам/  # Текущее задание
├── Templates/               # Системные шаблоны
├── Задание.txt              # Главное ТЗ проекта
└── docs/
    └── generation_guide.md  # Детальная документация по генерации
```

## 🎯 Три направления

| Магазин | Что делаем | Статус |
|---------|-----------|--------|
| **Футболки** | Генерация карточек с кастомными принтами (5 фото: перед/спина/бирка/модель×2) | 🔧 В работе |
| **Белье** | Виртуальные модели в белье с сохранением внешности реальных моделей | 📋 Подготовка |
| **Одежда** | Переработка скриншотов Авито в студийные фото + lifestyle | 📋 Подготовка |

## 🚀 Быстрый старт

1. Положи фото принта в папку задания
2. Добавь референс-фото модели (если нужна модель)
3. Опиши задачу в `Задание.txt`
4. Запусти генерацию через промпт из `prompts/templates/`
