# Шаблон: Одежда — Каталог + Lifestyle

## Каталожная съёмка

### CATALOG_FRONT
```
Professional e-commerce catalog photo of a [MODEL DESCRIPTION] wearing [CLOTHING DESCRIPTION]. Standing straight, facing camera, neutral expression. Clean [BACKGROUND COLOR] studio background. Even soft lighting, no harsh shadows. Camera: 50mm, f/5.6, full body framed with space above head and below feet. True-to-life color reproduction, realistic fabric draping. Aspect ratio 3:4.
```

### CATALOG_BACK
```
Professional e-commerce catalog photo, back view of a [MODEL DESCRIPTION] wearing [CLOTHING DESCRIPTION]. Clean [BACKGROUND COLOR] studio background. Even lighting, fabric texture clearly visible. Camera: 50mm, f/5.6. Aspect ratio 3:4.
```

## Lifestyle / Бренд-лента

### LIFESTYLE
```
Cinematic lifestyle photo of a [MODEL DESCRIPTION] wearing [CLOTHING DESCRIPTION]. [SCENE/ACTION DESCRIPTION]. [LOCATION]. Golden hour / evening ambient lighting. Camera: 35mm, f/1.8, cinematic color grading with [MOOD] tones. Shallow depth of field, bokeh in background. Realistic, editorial feel. Aspect ratio 4:5.
```

## Переработка скриншотов Авито

### AVITO_ENHANCE
```
Take this low-quality product screenshot and reimagine it as a professional studio photo. Product: [PRODUCT DESCRIPTION]. Remove any watermarks. Replace background with clean [BACKGROUND]. Add professional studio lighting: key light from left, soft fill, slight shadow for depth. Enhance fabric texture to show material quality. Color-accurate reproduction. Camera: 50mm, f/4. Aspect ratio 3:4.
```

## Переменные
- `[CLOTHING DESCRIPTION]` — полное описание вещи
- `[BACKGROUND COLOR]` — бежевый/светло-серый/белый
- `[SCENE/ACTION DESCRIPTION]` — что делает модель
- `[LOCATION]` — улица/кафе/квартира/балкон
- `[MOOD]` — тёплый/холодный/нейтральный
- `[PRODUCT DESCRIPTION]` — для переработки скриншотов
